# DAP-021: La documentación es parte del producto

**Estado:** Vigente  
**Fecha:** 2026-07-15  
**Clasificación:** Directriz Arquitectónica Permanente  

## Enunciado

Un Sprint NO termina cuando el código compila. Termina cuando existen ambos:

- ✅ Código funcionando
- ✅ Documentación actualizada

Si falta uno de los dos, el Sprint queda En Progreso.
