# DAP-017: Inmutabilidad Visual del Workspace

**Estado:** Vigente  
**Fecha:** 2026-07-15  
**Clasificación:** Directriz Arquitectónica Permanente  

---

## Enunciado

> Ninguna funcionalidad nueva podrá degradar la experiencia visual del Workspace.

---

## Interpretación

Cada nueva integración (Restafact, Microservice, DEV, WAMeta, Whaticket, Chat, etc.) deberá adaptarse al diseño del Workspace de COPE, no al revés.

Esto significa:

1. **No aparecerán nuevas ventanas** emergentes, modales o pantallas satélite para acomodar una integración.
2. **No aparecerán nuevos menús** laterales, pestañas horizontales o barras de navegación secundarias.
3. **No aparecerán nuevas barras laterales** dentro del contenido.
4. **No se agregarán botones** fuera de los módulos existentes (Cliente, Diagnóstico, Herramientas, Guías, Actividades, Resultado).
5. **No se romperá el layout de 4 columnas** (Sidebar → Bandeja → Conversación → Workspace).

---

## Cómo integrar correctamente

| Elemento COPE | Qué hacer con la nueva funcionalidad |
|---------------|--------------------------------------|
| Bandeja | Agregar un badge de canal. Los datos aparecen como una fila más en la inbox. |
| Conversación | El `ConversationRenderer` elige el renderizador adecuado. Nunca se reemplaza el panel. |
| Workspace — Cliente | Se agrega el campo si aplica. |
| Workspace — Diagnóstico | Se agrega una hipótesis o widget si aplica. |
| Workspace — Herramientas | Se agrega una tarjeta de herramienta si aplica. |
| Workspace — Resultado | Se agrega un campo si aplica. |

---

## Qué evitar

- ❌ "Vamos a agregar un botón aquí que abra Restafact en una nueva pestaña"
- ❌ "Vamos a poner una pestaña más en el panel derecho para los datos de Microservice"
- ❌ "Vamos a crear una nueva página para administrar DEV"

---

## Justificación

Dentro de dos o tres años, COPE debe seguir sintiéndose como un solo producto, no como una colección de herramientas pegadas entre sí.

Esta disciplina es la clave para que el proyecto madure como una plataforma SaaS sólida.

---

## Sanciones por violación

Toda implementación que viole esta DAP deberá ser rechazada en code review y corregida antes de mergear.
