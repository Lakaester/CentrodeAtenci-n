# DAP-022: Ningún prompt puede romper la documentación

**Estado:** Vigente  
**Fecha:** 2026-07-15  
**Clasificación:** Directriz Arquitectónica Permanente  

## Enunciado

Si OpenCode detecta que un cambio modifica arquitectura, dominio, endpoints, navegación o componentes, debe actualizar automáticamente la documentación correspondiente.

No esperar a que se lo pidan.
