# DAP-023: Cada Sprint debe producir una mejora visible

**Estado:** Vigente  
**Fecha:** 2026-07-15  
**Clasificación:** Directriz Arquitectónica Permanente  

## Enunciado

Cada Sprint debe producir una mejora visible para el Product Owner.

No basta con que exista un endpoint.  
No basta con que compile.  
No basta con que pasen los tests.  

El criterio de éxito será demostrable visualmente.
