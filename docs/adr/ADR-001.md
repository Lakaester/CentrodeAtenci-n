# ADR-001: Integración Zendesk — Anti Corruption Layer

**Estado:** Aprobado  
**Fecha:** 2026-07-15  
**Contexto:** COPE necesita integrarse con Zendesk como canal de atención. El dominio de COPE no debe conocer los modelos internos de Zendesk.

**Decisión:** Construir un módulo `modules/zendesk/` con Anti Corruption Layer (ACL) siguiendo Clean Architecture. Toda traducción entre el modelo Zendesk y el modelo COPE ocurre dentro de este módulo.

**Consecuencias:** 
- El dominio COPE nunca importa tipos de Zendesk.
- Agregar un nuevo canal (Whaticket, WAMeta) requiere crear otro módulo con la misma estructura.
- El ACL puede evolucionar independientemente del dominio COPE.
